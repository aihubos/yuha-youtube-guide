유하 · 초보 반응

· 모르면 바로 “그게 뭐예요?”
· 느낀 대로 말하기. 좋으면 좋다, 별로면 별로다
· ③에서는 어사이드 선배로 제레미에게 설명

04 · 첫 15초

훅 5가지 중 하나 고르기

촬영 마지막에 훅만 따로 3번 찍어 두면 편집이 쉬워요. 추천은 A와 D를 섞는 것.

A · 초보 선언형 추천
유하: 저 AI 앱, 오늘 처음 깔아봐요. 제레미: 오늘 이분이 AI 비서를 갖게 됩니다. 유하: 안 되면요? 제레미: 안 되는 것도 그대로 나갑니다.
B · 결과 먼저형

편집에서 완성 장면 3컷(첫 답장, 내 봇 이름, 웹페이지 완성)을 1초씩 붙이고:

제레미: 이게 전부 오늘 하루에 된 거예요. 유하: 저 진짜 아무것도 몰랐거든요.
C · 시청자 질문형
제레미: AI 설치만 하다가 지쳐서 닫아본 적 있으세요? 유하: 저요. 세 번요. 제레미: 오늘은 그 세 번을 같이 넘어볼게요.
D · 실수 선공개형 추천
유하: 어… 눌렀는데 아무 일도 안 일어나요. 제레미: 좋아요. 그게 오늘 첫 번째 막힘이에요. (자막) 이 영상, 막히는 것도 다 나옵니다
E · 역할 뒤집기형
유하: 어사이드는 제가 먼저 써봤어요. 제레미: 그럼 오늘은 어사이드는 유하님이 설명해 주세요. 유하: 대신 그록봇은 처음이에요. 잘 부탁드려요.
피할 훅: “이거 하나면 끝!”, “혁명” 같은 과장 표현. 광고처럼 보여요.

예시 프롬프트 · 눌러서 복사

그록봇 · 첫 인사

안녕, 나는 AI를 처음 써봐. 내가 오늘 해볼 만한 쉬운 일 3가지만 추천해 줘.

그록봇 · 귀찮은 일 시키기

이번 주 일정을 정리해서 표로 보여 줘. 내가 빠뜨린 게 있을지 물어봐 줘.

그록봇 · 내 봇 만들기

내 전용 비서 봇을 만들고 싶어. 이름은 내가 정할게. 하는 일: 하루 일정 요약, 답장 초안 쓰기. 말투: 친절하고 짧게. 먼저 나에게 필요한 걸 3가지만 질문해 줘.

더 구체적으로 다시 시키기

좋아, 그런데 너무 길어. 5줄 이내로, 오늘 할 일부터 먼저 보여 줘.

코덱스 · 웹페이지

내 소개 페이지를 만들어 줘. 흰 배경에 파란 버튼 하나, 사진 들어갈 자리 하나, 제목은 “안녕하세요, 유하입니다”. 완성되면 어떻게 열어 보는지 알려 줘.
따라 할 때 주의: 개인 정보(전화번호, 주소, 키)는 프롬프트에 넣지 않기. 연습용 정보로 해보세요.
08 · Herdr · 코덱스 쉽게

Herdr은 “AI 책상”,
코덱스는 “코딩 담당”

아래 명령은 이 가이드를 만든 컴퓨터에서 --help로 확인한 것만 적었어요. (Herdr 0.9.5 · 코덱스 0.164.0 기준)

코덱스 (Codex CLI)

한마디로 “말로 시키면 코드를 짜 주는 AI”. 처음엔 코드를 몰라도 만들고 싶은 걸 말하면 돼요. 앱으로 쓰는 방법도 있지만, 오늘은 터미널(검은 창)에서 보여 줘요.

시작하기 (대화형)

codex

처음 질문을 붙여서 시작

codex "내 소개 페이지를 만들어 줘"

한 번 실행하고 끝내기

codex exec "이 폴더에 무슨 파일이 있는지 쉬운 말로 알려 줘"

로그인 상태 확인 · 지난 대화 이어가기

codex login status codex resume --last

작업할 폴더를 지정해서 시작

codex --cd ~/yuha-page
카메라 앞 주의: --dangerously-bypass-approvals-and-sandbox 옵션은 도움말에 “매우 위험”이라고 적혀 있어요. 영상에서는 쓰지 않기.

Herdr (Herdr)

터미널 안에서 AI 여러 개를 창 여러 개로 나란히 띄우고, 각각 일하는 중 / 기다리는 중 / 승인 필요 / 끝남 상태를 보여 주는 프로그램. Herdr 도움말에 “코딩 에이전트용 터미널 작업 공간 관리자”라고 소개돼요.

시작 (이미 있으면 다시 붙기)

herdr

이름 붙인 방으로 시작

herdr --session yuha

상태 보기

herdr status
기본 단축키 설정 기본값 기준

먼저 Ctrl+B 를 누르고 손을 뗀 뒤 다음 키

V창을 좌우로 나누기
-창을 위아래로 나누기
C새 탭
H J K L왼쪽·아래·위·오른쪽 창으로 이동
Z지금 창을 크게 보기
?도움말
Q잠시 나가기 (세션은 유지)
AI 3개 띄우기 순서 화면에서 하는 법
1) herdr 실행 2) Ctrl+B → V (창 2개) 3) Ctrl+B → V (창 3개) 4) 첫 창: codex 둘째 창: claude 셋째 창: grok 5) 같은 질문을 3개에 던져서 답 비교하기

각 AI 명령(codex, claude, grok)은 이 컴퓨터에 설치돼 있어요. 유하님 컴퓨터에 설치·로그인이 돼 있는지는 촬영 전에 확인하세요.

고급: 명령어로 AI 다루기 구경용

Herdr 안에서 열린 창에서 쓰는 명령이에요. 영상에는 “이런 것도 돼요” 정도로만.

herdr agent list herdr agent prompt <이름> "한 줄 요약해 줘" --wait herdr agent read <이름>

비어 있는 셸 창에서 AI를 시작하는 명령은 herdr agent start <이름> --kind codex --pane <창ID> 형태예요. kind에는 codex, claude, grok 등이 있어요.

솔직하게: Herdr과 코덱스는 “처음 보면 어려워 보이는” 도구예요. 영상에서 “여기까지 어려우면 ④⑤는 건너뛰어도 돼요”라고 말해 주면 초보 시청자가 안심해요.

11 · 촬영 · 편집 팁

간단하게 찍는 법

화면 녹화 · 소리
  • 맥북 화면 녹화는 Shift+Cmd+5 로 시작 (영상 레퍼런스에서도 제일 먼저 막혔던 부분이라 미리 연습)
  • 화면 녹화 소리와 얼굴 카메라 소리는 따로 저장되니, 시작할 때 박수 한 번으로 싱크 표시
  • 화면 글씨는 크게. 브라우저 확대 125% 이상
  • 두 사람 모두 마이크 따로. 어렵다면 둘 사이에 1개라도 가깝게
B-roll로 쓸 컷
  • 타이핑하는 유하님 손, 입력 직후 화면에 글자가 올라오는 클로즈업
  • 답이 뜰 때 유하님 표정 (카메라 B로 따로 한 번 더)
  • 화면 전환용: 노트북 닫기, 커피 잔, 창밖
  • 로딩이 길 때 “기다리는 동안” 수다를 일부러 길게 찍기
편집 패턴
  • 핵심 단어만 큰 자막 (한 번에 1~2단어)
  • 설치 진행바 같은 기다림은 2배속 + 효과음
  • 화면 녹화 중엔 얼굴을 작은 창으로 계속 띄우기
  • 구간 시작마다 3초짜리 제목 카드 (예: “② 내 봇 만들기”)
광고처럼 안 보이게 중요
  • 실패·한계 장면 1개는 꼭 넣기 (예: 흐릿하게 시켜서 엉뚱한 결과 → 구체적으로 다시)
  • 유하님이 “별로였던 점”을 말하는 시간 15초 확보
  • “최고”, “혁명”, “무조건” 같은 단어 쓰지 않기
  • 협찬·제휴 관계가 있다면 설명란에 사실대로 적기

확인 필요 · 아직 못 확인한 것

  • 유하님이 그록봇을 설치하는 구체적 경로와 화면 (제레미가 촬영 전에 한 번 직접 확인)
  • 그록봇의 요금제·한도 (영상에서 말하려면 공식 안내 확인)
  • “그록봇 ↔ 어사이드 연결”이 실제로 가능한 범위 (리허설 필요. 안 되면 비교만)
  • 유하님 컴퓨터에 Herdr·코덱스·클로드·그록 CLI가 설치·로그인돼 있는지, 운영체제가 무엇인지
  • 위 Herdr 단축키는 설정 기본값이에요. 바꿔 놨다면 다를 수 있어요.
  • 숏츠 길이와 타임코드는 계획치예요. 편집 후 다시 맞추세요.
  • 레퍼런스 영상의 자막은 자동 생성이라 사람 이름 등에 오류가 있어 여기에는 쓰지 않았어요.
